# 進路コンパス

「決めなくていい進路相談」。8つの質問に答えると、ルールベース(AIは使わない)で進路の「候補」を整理するWebアプリです。ADHD傾向のある人でも迷いにくいよう、1問ずつ表示します。

## 仕組み

- 価値観5軸(自由度・ひとり好き・変化・スピード・意味)の5問 + 状況3問(お金・資格・場所)
- 7つの進路パス(会社員・スタートアップ・フリーランス・大学院/資格・地方移住・起業・副業から探る)と回答の距離を計算し、近い順に候補を出します
- 状況によるペナルティ(例: 今すぐ収入が必要なら起業の優先度を下げる)と注意書きを付けます
- 1位と2位が僅差、または全部遠いときは「まだ決めなくていい」と伝えます

## 使い方

`index.html` をブラウザで開くだけです。ビルド不要・外部通信なし。

## 調整したい場所

`index.html` 内の `QUESTIONS` / `CONSTRAINTS`(質問)と `PATHS`(進路の定義・ベクトル・ペナルティ)を編集します。
